# Dictionary Replacer

Replace $key$ placeholders in a string with corresponding values from a dictionary

Source: https://codingdojo.org/kata/DictionaryReplacer/

## TDD loop

1. **RED** — run the tests. `src/dictionary-replacer.ts` throws `"Not implemented"`, so the test in `src/dictionary-replacer.test.ts` fails.
2. **GREEN** — implement just enough in `src/dictionary-replacer.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run dictionary-replacer:test
```
