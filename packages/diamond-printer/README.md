# Diamond Printer

Print a diamond shape starting from 'A' with a given letter at its widest point

Source: https://codingdojo.org/kata/Diamond/

## TDD loop

1. **RED** — run the tests. `src/diamond-printer.ts` throws `"Not implemented"`, so the test in `src/diamond-printer.test.ts` fails.
2. **GREEN** — implement just enough in `src/diamond-printer.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run diamond-printer:test
```
