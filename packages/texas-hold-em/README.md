# Texas HoldEm

Rank and compare Texas Hold'Em poker hands for a televised championship show

Source: https://codingdojo.org/kata/TexasHoldEm/

## TDD loop

1. **RED** — run the tests. `src/texas-hold-em.ts` throws `"Not implemented"`, so the test in `src/texas-hold-em.test.ts` fails.
2. **GREEN** — implement just enough in `src/texas-hold-em.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run texas-hold-em:test
```
