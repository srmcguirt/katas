# Pagination Display

Render pagination controls (current, previous/next, first/last) for a given page set

Source: https://codingdojo.org/kata/PaginationSeven/

## TDD loop

1. **RED** — run the tests. `src/pagination-display.ts` throws `"Not implemented"`, so the test in `src/pagination-display.test.ts` fails.
2. **GREEN** — implement just enough in `src/pagination-display.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run pagination-display:test
```
