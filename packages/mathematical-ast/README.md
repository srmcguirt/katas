# Mathematical AST

Parse an RPN mathematical expression string into an abstract syntax tree

Source: https://codingdojo.org/kata/mathematical-ast/

## TDD loop

1. **RED** — run the tests. `src/mathematical-ast.ts` throws `"Not implemented"`, so the test in `src/mathematical-ast.test.ts` fails.
2. **GREEN** — implement just enough in `src/mathematical-ast.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run mathematical-ast:test
```
