# Word Wrap

Insert line breaks into a string so no line exceeds a given column width, breaking at word boundaries

Source: https://codingdojo.org/kata/WordWrap/

## TDD loop

1. **RED** — run the tests. `src/word-wrap.ts` throws `"Not implemented"`, so the test in `src/word-wrap.test.ts` fails.
2. **GREEN** — implement just enough in `src/word-wrap.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run word-wrap:test
```
