# RPN Calculator

Evaluate arithmetic expressions written in Reverse Polish Notation

Source: https://codingdojo.org/kata/RPN/

## TDD loop

1. **RED** — run the tests. `src/rpn-calculator.ts` throws `"Not implemented"`, so the test in `src/rpn-calculator.test.ts` fails.
2. **GREEN** — implement just enough in `src/rpn-calculator.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run rpn-calculator:test
```
