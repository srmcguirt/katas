# FooBarQix

Replace numbers divisible by or containing 3, 5, or 7 with Foo, Bar, and Qix respectively

Source: https://codingdojo.org/kata/FooBarQix/

## TDD loop

1. **RED** — run the tests. `src/foobarqix.ts` throws `"Not implemented"`, so the test in `src/foobarqix.test.ts` fails.
2. **GREEN** — implement just enough in `src/foobarqix.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run foobarqix:test
```
