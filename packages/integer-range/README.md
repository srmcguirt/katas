# Integer Range

Implement an integer range type supporting contains, overlap, endpoints, and enumeration

Source: https://codingdojo.org/kata/Range/

## TDD loop

1. **RED** — run the tests. `src/integer-range.ts` throws `"Not implemented"`, so the test in `src/integer-range.test.ts` fails.
2. **GREEN** — implement just enough in `src/integer-range.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run integer-range:test
```
