# Social Network

Build a light social network supporting posting, reading, following, mentions, links, and direct messages

Source: https://codingdojo.org/kata/social-network/

## TDD loop

1. **RED** — run the tests. `src/social-network.ts` throws `"Not implemented"`, so the test in `src/social-network.test.ts` fails.
2. **GREEN** — implement just enough in `src/social-network.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run social-network:test
```
