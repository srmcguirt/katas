# Tennis Score

Track and report the score of a tennis game using love/15/30/40/deuce/advantage rules

Source: https://codingdojo.org/kata/Tennis/

## TDD loop

1. **RED** — run the tests. `src/tennis-score.ts` throws `"Not implemented"`, so the test in `src/tennis-score.test.ts` fails.
2. **GREEN** — implement just enough in `src/tennis-score.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run tennis-score:test
```
