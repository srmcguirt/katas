# Wallet

Compute the total value of a wallet's mixed-currency stock holdings in a target currency

Source: https://codingdojo.org/kata/Wallet/

## TDD loop

1. **RED** — run the tests. `src/wallet.ts` throws `"Not implemented"`, so the test in `src/wallet.test.ts` fails.
2. **GREEN** — implement just enough in `src/wallet.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run wallet:test
```
