# Tic Tac Toe

Build a two-player tic-tac-toe game that detects wins, draws, and invalid moves

Source: https://codingdojo.org/kata/tic-tac-toe/

## TDD loop

1. **RED** — run the tests. `src/tic-tac-toe.ts` throws `"Not implemented"`, so the test in `src/tic-tac-toe.test.ts` fails.
2. **GREEN** — implement just enough in `src/tic-tac-toe.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run tic-tac-toe:test
```
