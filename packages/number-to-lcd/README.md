# Number To LCD

Render an arbitrary-digit number as stylized 3-line-high LCD-style digits

Source: https://codingdojo.org/kata/NumberToLCD/

## TDD loop

1. **RED** — run the tests. `src/number-to-lcd.ts` throws `"Not implemented"`, so the test in `src/number-to-lcd.test.ts` fails.
2. **GREEN** — implement just enough in `src/number-to-lcd.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run number-to-lcd:test
```
