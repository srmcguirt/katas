# Args

Parse command-line flag arguments (booleans, strings, integers) into usable values

Source: https://codingdojo.org/kata/Args/

## TDD loop

1. **RED** — run the tests. `src/args.ts` throws `"Not implemented"`, so the test in `src/args.test.ts` fails.
2. **GREEN** — implement just enough in `src/args.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run args:test
```
