# Reversi

Given a Reversi board and whose turn it is, return the list of legal flipping moves

Source: https://codingdojo.org/kata/Reversi/

## TDD loop

1. **RED** — run the tests. `src/reversi.ts` throws `"Not implemented"`, so the test in `src/reversi.test.ts` fails.
2. **GREEN** — implement just enough in `src/reversi.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run reversi:test
```
