# Roman Numeral Calculator

Add two Roman numeral strings together without converting to integers

Source: https://codingdojo.org/kata/RomanCalculator/

## TDD loop

1. **RED** — run the tests. `src/roman-numeral-calculator.ts` throws `"Not implemented"`, so the test in `src/roman-numeral-calculator.test.ts` fails.
2. **GREEN** — implement just enough in `src/roman-numeral-calculator.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

