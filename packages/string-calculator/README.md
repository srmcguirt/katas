# String Calculator

Sum comma/newline-delimited numbers passed as one string

Source: https://codingdojo.org/kata/StringCalculator/

## TDD loop

1. **RED** — run the tests. `src/string-calculator.ts` throws `"Not implemented"`, so the test in `src/string-calculator.test.ts` fails.
2. **GREEN** — implement just enough in `src/string-calculator.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run string-calculator:test
```
