# Birthday Greetings

Send an automated birthday email to each friend in a flat file on their date of birth

Source: https://codingdojo.org/kata/birthday-greetings/

## TDD loop

1. **RED** — run the tests. `src/birthday-greetings.ts` throws `"Not implemented"`, so the test in `src/birthday-greetings.test.ts` fails.
2. **GREEN** — implement just enough in `src/birthday-greetings.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run birthday-greetings:test
```
