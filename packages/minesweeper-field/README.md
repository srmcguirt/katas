# Minesweeper Field

Given mine locations on an MxN field, print the count of adjacent mines for each cell

Source: https://codingdojo.org/kata/Minesweeper/

## TDD loop

1. **RED** — run the tests. `src/minesweeper-field.ts` throws `"Not implemented"`, so the test in `src/minesweeper-field.test.ts` fails.
2. **GREEN** — implement just enough in `src/minesweeper-field.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run minesweeper-field:test
```
