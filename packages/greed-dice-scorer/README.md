# Greed Dice Scorer

Score a roll of up to six dice according to the Greed dice game scoring rules

Source: https://codingdojo.org/kata/Greed/

## TDD loop

1. **RED** — run the tests. `src/greed-dice-scorer.ts` throws `"Not implemented"`, so the test in `src/greed-dice-scorer.test.ts` fails.
2. **GREEN** — implement just enough in `src/greed-dice-scorer.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run greed-dice-scorer:test
```
