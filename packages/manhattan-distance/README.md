# Manhattan Distance

Compute the Manhattan (taxicab) distance between two grid points

Source: https://codingdojo.org/kata/manhattan-distance/

## TDD loop

1. **RED** — run the tests. `src/manhattan-distance.ts` throws `"Not implemented"`, so the test in `src/manhattan-distance.test.ts` fails.
2. **GREEN** — implement just enough in `src/manhattan-distance.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

