# Substitution Cipher

Encrypt and decrypt messages using a fixed alphabet-to-symbol decryption key

Source: https://codingdojo.org/kata/CodeCracker/

## TDD loop

1. **RED** — run the tests. `src/substitution-cipher.ts` throws `"Not implemented"`, so the test in `src/substitution-cipher.test.ts` fails.
2. **GREEN** — implement just enough in `src/substitution-cipher.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.
