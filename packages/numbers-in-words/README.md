# Numbers In Words

Convert a numeric monetary amount into its written-out word form

Source: https://codingdojo.org/kata/NumbersInWords/

## TDD loop

1. **RED** — run the tests. `src/numbers-in-words.ts` throws `"Not implemented"`, so the test in `src/numbers-in-words.test.ts` fails.
2. **GREEN** — implement just enough in `src/numbers-in-words.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run numbers-in-words:test
```
