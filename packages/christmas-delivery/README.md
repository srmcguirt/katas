# Christmas Delivery

Coordinate multiple elves loading presents onto a sleigh concurrently instead of one at a time

Source: https://codingdojo.org/kata/christmas-delivery/

## TDD loop

1. **RED** — run the tests. `src/christmas-delivery.ts` throws `"Not implemented"`, so the test in `src/christmas-delivery.test.ts` fails.
2. **GREEN** — implement just enough in `src/christmas-delivery.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run christmas-delivery:test
```
