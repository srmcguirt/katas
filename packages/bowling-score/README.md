# Bowling Score

Calculate the total score for a valid sequence of rolls in one game of ten-pin bowling

Source: https://codingdojo.org/kata/Bowling/

## TDD loop

1. **RED** — run the tests. `src/bowling-score.ts` throws `"Not implemented"`, so the test in `src/bowling-score.test.ts` fails.
2. **GREEN** — implement just enough in `src/bowling-score.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run bowling-score:test
```
