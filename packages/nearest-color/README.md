# Nearest Color

Find the nearest named color to a given RGB or hex color value

Source: https://codingdojo.org/kata/NearestColor/

## TDD loop

1. **RED** — run the tests. `src/nearest-color.ts` throws `"Not implemented"`, so the test in `src/nearest-color.test.ts` fails.
2. **GREEN** — implement just enough in `src/nearest-color.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run nearest-color:test
```
