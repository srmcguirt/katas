# Roman Numerals

Convert integers to their Roman numeral representation

Source: https://codingdojo.org/kata/RomanNumerals/

## TDD loop

1. **RED** — run the tests. `src/roman-numerals.ts` throws `"Not implemented"`, so the test in `src/roman-numerals.test.ts` fails.
2. **GREEN** — implement just enough in `src/roman-numerals.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run roman-numerals:test
```
