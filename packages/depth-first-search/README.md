# Depth First Search

Implement depth-first traversal of a graph or maze using the call stack, discovered interactively

Source: https://codingdojo.org/kata/DepthFirstSearch/

## TDD loop

1. **RED** — run the tests. `src/depth-first-search.ts` throws `"Not implemented"`, so the test in `src/depth-first-search.test.ts` fails.
2. **GREEN** — implement just enough in `src/depth-first-search.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run depth-first-search:test
```
