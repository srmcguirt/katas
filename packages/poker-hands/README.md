# Poker Hands

Compare pairs of five-card poker hands and determine which ranks higher

Source: https://codingdojo.org/kata/PokerHands/

## TDD loop

1. **RED** — run the tests. `src/poker-hands.ts` throws `"Not implemented"`, so the test in `src/poker-hands.test.ts` fails.
2. **GREEN** — implement just enough in `src/poker-hands.ts` to make the test pass.
3. **REFACTOR** — clean up the implementation while keeping the test green. Add more test cases as needed.

Run tests for this package:

```
bun test
```

Or via moon:

```
moon run poker-hands:test
```
